2. HOW TO RUN THE GAME
------------------------------------------------------------------------
Method A (Web Browser - Recommended):
1. Open terminal in game directory and run:
   npx -y serve@latest -l 8086
   or:
   python3 -m http.server 8086
2. Open browser at: http://localhost:8086

Method B (Windows Standalone Build):
Double-click MyGame.exe or ColdForgeGames.exe in the release folder.
